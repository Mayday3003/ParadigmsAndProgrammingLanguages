Fundamentos del lenguaje

1. ¿Qué es Scala y para qué se utiliza?

Scala es un lenguaje que mezcla dos maneras de programar: orientada a objetos y funcional. Corre sobre la máquina virtual de Java (JVM), así que también puede usar un montón de herramientas de Java.

¿Para qué sirve? Para sistemas de empresas, servicios que funcionan por detrás de una aplicación y análisis de datos. La ventaja es que permite trabajar listas y datos sin estar cambiándolos a cada rato.

Los ejemplos de esta guía usan sintaxis común a Scala 2.13 y Scala 3, a menos que se avise algo distinto.

2. Primer programa: object, main y println

Con object armas un objeto único; main indica dónde comienza el programa y println muestra el resultado en pantalla.

Ejemplo completo
object HolaScala {
  def main(args: Array[String]): Unit = {
    println("¡Hola desde Scala!")
  }
}
Salida: ¡Hola desde Scala!

En IntelliJ IDEA crea un proyecto Scala con sbt, guarda HolaScala.scala en src/main/scala y ejecuta el objeto. ¡Así de sencillo!

3. Variables, constantes y tipos de datos

val guarda una referencia que no se puede reasignar; var deja cambiarla. Los tipos más comunes son Int, Double, Boolean y String. En programación funcional normalmente preferimos val.

val nombre: String = "Ana"
val edad: Int = 21
val promedio: Double = 4.5
val activo: Boolean = true
var intentos: Int = 0
intentos += 1
println(s"$nombre tiene $edad años")

Si le pones s antes de las comillas, puedes meter variables dentro del texto con $variable.

4. Entrada de datos por teclado

StdIn.readLine() lee lo que escribes. Con toIntOption intentas pasarlo a entero sin que el programa se caiga si alguien escribe otra cosa.

import scala.io.StdIn

object Entrada {
  def main(args: Array[String]): Unit = {
    print("Ingrese su edad: ")
    val edad = StdIn.readLine().toIntOption
    println(edad.getOrElse(0))
  }
}

Si escribes 23, sale 23. Si ingresas letras, el ejemplo muestra 0. En un sistema real conviene avisar el error y pedir el dato de nuevo.

5. Operadores y expresiones

Para hacer cuentas usas +, -, *, / y %. Para comparar tienes ==, !=, > y <. Y para combinar condiciones, &&, || y !.

val a = 12
val b = 5
println(a + b)        // 17
println(a / b)        // 2: división entera
println(a.toDouble / b) // 2.4
println(a > b && b > 0) // true
Manos a la obraPide dos números por teclado, comprueba que ambos sean enteros y muestra suma, resta, multiplicación y división. Evita dividir entre cero.

Condicionales, ciclos y colecciones

6. Condicionales: if, else if y else

Con if eliges qué hacer según una condición. Ten presente que en Scala también puede devolver un valor que guardas directamente en un val.

val nota = 4.2
val estado = if (nota >= 3.0) "Aprobado" else "Reprobado"
println(estado)

val nivel = if (nota >= 4.5) "Excelente"
            else if (nota >= 3.0) "Suficiente"
            else "Insuficiente"

7. Condicionales por patrones con match

Con match revisas diferentes casos y obtienes un resultado. El guion bajo _ funciona como el caso de respaldo cuando ninguno coincide.

val opcion = 2
val mensaje = opcion match {
  case 1 => "Registrar"
  case 2 => "Consultar"
  case 3 => "Salir"
  case _ => "Opción desconocida"
}
println(mensaje)

8. Ciclos: for y while

Los ciclos sirven para repetir tareas. for recorre rangos o colecciones y while repite mientras algo se cumpla. Más adelante vamos a reemplazar muchos ciclos por operaciones funcionales.

for (numero <- 1 to 5) {
  println(numero)
}

var contador = 1
while (contador <= 3) {
  println(contador)
  contador += 1
}

1 to 5 llega hasta el 5; 1 until 5 termina en 4. El viejo do ... while existe en Scala 2, pero no en Scala 3; por eso acá evitamos usarlo.

9. Listas, vectores, conjuntos y mapas

Con List y Vector armas colecciones inmutables; Set evita repetidos, y Map guarda parejas de clave y valor. Cada una resuelve una necesidad distinta.

val edades = List(18, 21, 19)
val ciudades = Vector("Medellín", "Bello")
val codigos = Set(101, 101, 102)
val precios = Map("Pan" -> 2500, "Leche" -> 4800)

println(edades.head)             // 18
println(ciudades(1))             // Bello
println(codigos.size)            // 2
println(precios.get("Pan"))      // Some(2500)

10. Funciones propias con def

Una función recibe datos, hace una operación y entrega un resultado. La palabra def la define y el tipo después de los dos puntos dice qué devuelve.

def calcularDescuento(precio: Double, porcentaje: Double): Double = {
  precio * porcentaje / 100
}

val descuento = calcularDescuento(100000, 10)
println(descuento) // 10000.0
Manos a la obraIngresa una cantidad N de precios desde teclado, guárdalos en una lista y clasifica cada precio según un rango definido por el negocio. Muestra el total y el promedio; revisa qué pasa si N es cero.
